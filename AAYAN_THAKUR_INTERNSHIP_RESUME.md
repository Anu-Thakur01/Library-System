## Projects

### Library Management System

Technology: ASP.NET Core MVC, C#, Entity Framework Core, PostgreSQL, Bootstrap

Built a library management system to manage books, authors, categories, publications, members, borrowing, returns, and reports.

Key features:

- User login and role-based access
- Book management
- Author management
- Member management
- Borrow and return management
- PostgreSQL database integration
- Member phone and Gmail validation
- Case-insensitive member search
- Light and dark mode UI
- Clean table actions for edit, status change, and delete
